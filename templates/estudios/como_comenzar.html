Cómo cargar una investigación

El recorrido desde que tenés un estudio en mente hasta que queda cargado.

  1. Definí el estudio antes de cargarlo

    Tené claro el título, el tema, de dónde van a salir los datos y la temporalidad. Son las preguntas del apartado Sobre el estudio, y conviene resolverlas antes de sentarse a completar el formulario.

  2. Cargá la investigación

    Entrá a {% if puede_editar %} Cargar nueva investigación {% else %} Cargar nueva investigación {% endif %} y completá los tres apartados. Para guardar son obligatorios el título, el teléfono y el mail de contacto; el resto se puede completar después.

  3. Si elegís "otras fuentes", especificá cuáles

    En la pregunta sobre el origen de los datos, la opción De otras fuentes habilita un campo de texto para detallarlas. Ese detalle se guarda solo si esa opción queda elegida.

  4. Verificá que quedó cargada

    Después de guardar vas a caer en Consultar el repositorio, donde cada investigación es una tarjeta. Buscá la tuya con el filtro y tocala: se abre su ficha con todos los datos como los cargaste.

  5. Corregí o completá cuando haga falta

    Con {% if puede_editar %} Modificar investigación cargada {% else %} Modificar investigación cargada {% endif %} buscás por título, se abre el formulario con todo lo guardado y cambiás lo que necesites.

Cosas para tener en cuenta

  1. Quién cargó cada investigación queda registrado

    Al guardar se anota tu usuario y la fecha, y cada modificación actualiza la fecha de última edición. Se ve en el repositorio.

  2. Los títulos pueden repetirse

    Nada impide cargar dos investigaciones con el mismo título, pero después la búsqueda por título te va a devolver las dos. Usá títulos que se distingan.

  3. Solo vos podés modificar lo que cargaste

    Las investigaciones se pueden consultar entre todos, pero para modificar una hay que haberla cargado: se compara el DNI con el que entraste. Si no coincide, la app no te deja editarla.
